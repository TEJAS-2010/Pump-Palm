Pump PulsePhone walkthrough

Connect the ESP32

The computer forwards your ESP32 readings. Your phone displays them in the browser.

USB setup

  1. On the computer, run the complete Arduino sketch and confirm the Serial Monitor shows lines beginning with Raw: at 115200 baud. Close the Serial Monitor to release the USB port.
  2. In Pump Pulse, save a field and open Arduino & salinity. Tap Pair Arduino and keep the one-time device token private.
  3. From the project folder on the computer, run the commands below. Replace COM3 with the port shown in your Arduino IDE and use the base address of your Pump Pulse deployment.
python -m pip install pyserial
python firmware/serial_bridge.py COM3 https://YOUR-PUMP-PULSE-SITE

Enter the token when prompted. On your phone, sign into the same Pump Pulse account and open Arduino & salinity. Match the newest raw count to the bridge output.

A private preview may require additional hosting access. If the bridge receives a sign-in response, use an authorized API route on your deployment. Keep the device token separate from hosting credentials.
