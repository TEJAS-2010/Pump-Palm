Falaj FieldsPhone walkthrough

Connect the ESP32

The computer forwards your ESP32 readings. Your phone displays them in the browser.

USB setup

  1. On the computer, run the complete Arduino sketch and confirm the Serial Monitor shows lines beginning with Raw: at 115200 baud. Close the Serial Monitor to release the USB port.
  2. In Falaj Fields, save a field and open Reading setup. Tap Connect a sensor and keep the one-time device token private.
  3. Download the USB bridge to your computer. Open a terminal in the download folder, then run the commands below. Replace COM3 with the port shown in your Arduino IDE.

Raw wetness readings need soil-specific calibration for moisture alerts. The bridge can also forward JSON readings with calibrated moisture_pct, soil soil_ec_dsm, or irrigation water ecw_dsm.

python -m pip install pyserial
python serial_bridge.py COM3 https://pump-palm.vercel.app

Enter the token when prompted. On your phone, sign into the same Falaj Fields account and open Reading setup. Open Soil moisture or Salinity to see the latest calibrated reading and its time. The setup table also displays raw counts for bench testing. A successful upload prints HTTP 202.

A private preview may require additional hosting access. If the bridge receives a sign-in response, use an authorized API route on your deployment. Keep the device token separate from hosting credentials.
